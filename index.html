새 수집을 요청할 권한 연결

새로고침 버튼이 GitHub Actions를 실행하도록 이 탭에 실행 권한을 연결합니다.

  1. 개인 GitHub 계정에서 아래 링크를 엽니다.
  2. Only select repositories에서 linkedin-follower-race 하나만 선택합니다.
  3. Repository permissions → Actions: Read and write로 실행 권한 키를 만듭니다.
GitHub에서 실행 권한 만들기 ↗

키는 열린 탭의 메모리에만 유지합니다. 서버·저장소·브라우저 저장 공간에 저장하지 않으며, 탭을 닫으면 연결이 해제됩니다.
